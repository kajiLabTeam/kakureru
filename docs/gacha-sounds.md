# かくれるガチャの効果音

かくれるガチャ（`lib/features/mission/view/gacha/`）で鳴らす効果音の一覧、出どころ、ライセンス（issue #160）。

## 音源の一覧

置き場所: `assets/sounds/gacha/`（22050Hz・モノラル・16bit WAV）

| ファイル | 鳴らす段（`GachaPhase`） | 音 | 長さ |
|---|---|---|---|
| `turning.wav` | `turning`: ハンドルを回す | カチカチ（12回、だんだん速く強く） | 1.5秒 |
| `heat.wav` | `heat`: 激熱 | 低い唸りの溜め（うねりがだんだん速くなる） | 1.4秒 |
| `drop.wav` | `capsule`: カプセルが落ちる | コロン（着地0.464秒と弾み0.704秒に合わせる） | 0.8秒 |
| `fanfare.wav` | `confirmed`: 確定 | ド・ミ・ソと上がって和音を伸ばすファンファーレ | 1.9秒 |
| `miss.wav` | `missed`: ハズレ | 短く低い「ブッブー」（#158の短い演出に合わせる） | 0.5秒 |

振動は確定で700msを1回、ハズレで120msを1回。

## 出どころとライセンス

**どの音も外部の素材ではない。** `scripts/generate_gacha_sounds.py` が正弦波・矩形波・ノイズを重ねて合成した、このリポジトリで作ったものである。他人の著作物を含まないため、外部ライセンスの表記やクレジットは要らない。扱いはこのリポジトリのほかのコードと同じ。

作り直すとき（長さ・音色を変えるとき）はスクリプトを書き換えて実行する。標準ライブラリだけで動く。

```sh
python3 scripts/generate_gacha_sounds.py
```

**あとからフリー素材に差し替える場合は**、商用利用と改変が許されている素材だけを使い、この表にファイルごとの「配布元URL・作者・ライセンス名・取得日」を追記すること。

## 鳴らし方の決まり

- **メディアの音量で鳴らす**（audioplayers の `AudioContextConfigFocus.mixWithOthers`。Androidでは usage=media、オーディオフォーカスは取らない）。ほかのアプリの音楽は止めない。
- **通知の音はOFFのまま**。隠れている人の位置がばれないよう、ミッション通知は `playSound: false` のまま（`lib/core/utils/local_notifications.dart`）。
- **音は常にON**（アプリ内のON/OFF設定は置かない）。鳴らしたくないときは端末のメディア音量で下げる。
